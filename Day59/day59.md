## 🧠 Key Learnings
1. **The Importance of an Open Source License:** A public repository without a license technically means "all rights reserved." Adding an MIT License is a critical step for portfolio projects so recruiters and other developers know they are permitted to evaluate or fork the code.
2. **Repo Discoverability:** Adding proper GitHub topics (`agentic-ai`, `rag`, `langgraph`) and placing the live URL in the "About" section is vital for making the project look professional and easily accessible to non-technical stakeholders.
3. **Trusting Git over Cached Tools:** I encountered a situation where an external fetch tool falsely claimed a deleted file (`test_groq.py`) was still in the repo. Trusting local `git status` output over third-party cache proved to be the right debugging approach.
