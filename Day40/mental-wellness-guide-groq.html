System Prompt Design

This assistant uses a warm, validating approach with three core phases:

Listen & Validate: Acknowledges feelings without judgment

Clarify: Asks clarifying questions to deepen understanding

Guide: Provides a step-by-step relief exercise + actionable next steps

UI Design Philosophy

The interface prioritizes calm over clutter:

• Soft colors and breathing animations reduce anxiety

• Large input field encourages expression

• Phased reveal (welcome → processing → response) creates presence

• Interactive exercise gives immediate actionability

How to Extend

Add memory: Store past sessions in localStorage to show progress over time

Add tools: Integrate with calendar for scheduling meditation, or with wearables for stress tracking

Personalize exercises: Offer multiple relief techniques (progressive muscle relaxation, grounding, visualization)

Follow-up messaging: Send reminders or check-ins based on user's stated stressors
